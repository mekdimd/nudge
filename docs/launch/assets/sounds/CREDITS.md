# Sound credits

Nudge's start.wav, tick.wav, attention.wav and success.wav come from nudge.ui.sounds.synth(TONES) and use the project's MIT license.

click-soft.mp3 comes from HyperFrames' bundled media-use sound effects. Its [upstream credits](PIXABAY_SOURCE_CREDITS.md) identify Pixabay as the source and specify the [Pixabay Content License](https://pixabay.com/service/license-summary/). The original credits describe the full upstream collection; this project includes only click-soft.mp3 from that collection.

The click file is a build input for the launch video. The rendered video combines it with Nudge's footage, music and motion. See [the film's asset notes](../../ASSETS.md) for reuse and attribution.

Keyboard audio in typing.mp3 is "Keyboard Typing Sounds" by crz1990, from https://freesound.org/people/crz1990/sounds/135872/. It uses [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). HyperFrames media-use retrieved it through Openverse. The film shortens it into accents during YouTube search, subject editing and form typing. Include the attribution when sharing the film.
