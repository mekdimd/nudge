# Bank demo design

Reading this as a banking portal for personal account holders, with a modern, restrained visual style. This is a visual overhaul of the sample bank, with the statement download path preserved.

The design-taste-frontend skill's audit and typography rules informed the redesign. Its marketing-page layouts do not apply to this product interface. The frontend-design skill supplied the compact colour, type and layout plan.

## Audit and choices

The previous design used large identical panels, default blue buttons, oversized headings and little account detail. The redesign uses white and cool-grey backgrounds, #21644f for primary actions, #e8f2eb for selected navigation, #1c2926 for text and #687570 for secondary text. Inter supports compact banking labels and tabular balances. Borders organize accounts and transactions; shadows do not decorate every panel.

Design variance is 3, motion intensity is 2 and visual density is 5. The account summary and money-management panel use unequal columns. The statement list uses real table headings and accessible action names. The detail page pairs a document preview with file and period information.

The visual style is a custom fictional bank identity, not an implementation of another bank's design system. Lucide supplies the icons. All visible data is sample data, and deposits minus debits reconcile with the displayed closing balances.

## Verification

Check desktop and narrow layouts, focus outlines, text and button contrast, dark mode, loaded fonts and icons, and the statement download result before recording. No decorative gradients, arbitrary metadata labels, marketing claims, em dashes or fake screenshots belong in this page. The browser UI itself is functional.
